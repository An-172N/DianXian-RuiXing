点线锐山行 ~ Thunder Out of the Mountain
=

**这是自己正在做的一款小游戏**

**在今年（2025）年初开始做的**

**一开始的几个月是想着做STG游戏的** *（没错，我是个东方众*

**然而自己不会设计弹幕** *（数学不会口牙*

**所以在7月份就想着重做成打砖块游戏** *（看着东方灵异传就有了灵感了*

**设定是有（4x，3x）2√+1关** *（因为懒*

*（懒成两个月连第一关都没做完整*

**先说一下玩法吧**

**Z 是发射子弹**

**X 是瞬解放**

**L-SHIFT 是慢移动**

**← 是向左移动**

**→ 是向右移动**


**八个形力才能触发一次瞬解放**

**有蓝色、绿色形点**

**蓝色形点增加形力**

**绿色形点增加形闪**
