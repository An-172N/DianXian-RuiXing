## 按键说明书  
- ### 主界面
  - 按 Enter 开始嗨皮
  - 按 Q 则不打了
- ### 游戏ing
  - 长按 z 是蓄力
    - 松开后会根据蓄力点释放常形力 *（就是发射子弹* 
  - 长按 x 为悬浮模式 *（就是快移动*
  - 按 c 则是释放形分 *（也就是 Bomb*
  - 在对话中按 z 看下一则对话
    - 也可以按x跳过
  - 按 Esc 休息一下
- ### 休息ing
  - 按 Esc 休息完了
  - 不想玩就按 q 吧 *（按完就返回主界面了*
- ### 存记录
  - 按 Esc 不存
  - 按 Enter 存
  - 可以用键盘打英文上去

## 说一下规则吧  
- ### K.璃
  - 形点
    - 白色为蓄力点
      - 拾到时可以根据是否蓄力释放常形力 *（就是biu*
    - 蓝色为形力点
      - 拾到可以加形力 *（就是火力*
    - 绿色为形闪点
      - 可以增加形闪次数 *（闪避！*
  - “矩澜雨” *（Bomb*
    - 每释放一次则会消耗12点形力
    - 释放时会有3秒的无敌时间
  - 蓄力
    - 会根据蓄力点来连续释放常形力
    - 最多可以蓄 6 个点
  - 连击 *（捡*
    - 形力点和形闪点才能加连击
    - 拾到任何形点倒计时会重置到2秒
    - 倒计时结束会额外加分
- ### 分数
  - 击中目标每颗子弹 + 64 分
  - 连击倒计时结束时 + 2 ^ 连击 分
  - 结算
    - 得点结算公式：得点 x 512 + 2 ^ 连击 + 连击 * 2
    - 无伤计算公式：连续无伤过关数 x 4096
- ### 弹幕
  - 每一关的弹幕都有不同的样子
  - 弹幕为白色时碰到不会触发形闪
  - 击落砖块生成弹幕概率
    - 第一面：0.17 + 0.02
    - 第二面：0.17 + 0.03
    - 第三面：0.17 + 0.05
    - Extra面：0.17 + 0.08
- ### 砖块
  - 每一关的砖块都是不同的
  - 白色砖块会结合附近的砖块类型、攻击形力以及自身产生不同的爆破 *（说人话就是每个面的白色砖块有不同的爆炸效果*
