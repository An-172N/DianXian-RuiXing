## 按键说明书
- ### 主界面
  - 按 Z 开始爬山 *（开玩*
  - 按 C 查看日志 *（没有日志的话就当木鱼吧*
  - 按 Q Say~ Goodbye
- ### 游戏ing
  - 按 ←→ 左右移动
  - 在对话中按 Z 下一则对话
    - 也可以按 X 跳过
  - 按 Esc 休息一下
  - 主主角操控看[主主角](#主主角)吧
- ### 休息ing
  - 按 Esc 休息完了
  - 不想爬就按 Del 吧 *（按完就返回主界面了*
- ### 存日志
  - 按 Esc 不存
  - 按 Enter 存 *（存在 用户根目录/Saved Games/DX00 里*
  - 可以存致谢人的名称 *（最多 8 个字符*
- ### 看日志
  - 按 Esc 合上
  - 按 Del 扔掉
  - 翻页则按 ←→

## 主主角
- ### K.璃
  - 形分
    - 按 Space 释放形分
    - 每释放一次会消耗 12 点形力
    - 释放后会有 3 秒无敌时间
  - 形态
    - 长按 X 切换为特殊形态
      - 一旦松开会切换回正常形态
    - 正常形态为落地状态 *（普速移动*
    - 特殊形态为悬浮状态 *（高速移动*
  - 形击
    - 长按 Z 蓄力发射子弹
      - 否则拾一次形点立刻形击一次
    - 会根据蓄力点进行连续形击
      - 最多能蓄 3 点
      - 每形击一次消耗 1 点蓄力
    - 会根据形力点调整形击威力
      - 最多能蓄 32 点
      - 每 16 的倍数点提升一次形力

## 说一下规则吧
- ### 形点
  - 白色为蓄力点 *（事实上其它点也是蓄力点*
  - 蓝色为形力点 *（火力*
  - 绿色为形闪点 *（残机*
- ### 连击
  - 只有形力点和形闪点才能加连击 *（其实就是捡形点*
  - 拾到任何形点倒计时会重置为 2 秒
  - 倒计时结束会额外[加分](#分数)
- ### 分数
  - 子弹每击中目标 + 64
  - 连击倒计时结束或子站结束 + 2 ^ 连击 *（连击 > 0*
  - 结算 *（基础分 + (结束分 if 子站 == 6 else 0)*
    - 基础
      - 得点结算：得点 * 512
      - 无闪结算：连续无闪过站数 * 4096
    - 结束
      - 面数结算：面数 * 16384
      - 形力结算：形力 / 32 * 8192
- ### 砖块
  - 击落砖块会
    - 有概率生成[弹幕](#弹幕)
    - 可能会掉落特殊形点，每站掉落数量为 *（子站 <= 5）*
      - 形力点：4 + 面数 + 子站
      - 形闪点：1
  - 白色砖块会有“惊喜”哦
- ### 弹幕
  - 有些弹幕会有点不同
  - 击落砖块生成弹幕概率为
    - 0.17 + 形力 / 1000 + *（斐波那契数*
      - 第一面：0.05
      - 第二面：0.08
      - 第三面：0.13
