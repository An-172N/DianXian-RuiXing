## 按键说明书  
- ### 主界面
  - 按 Enter 开始嗨皮
  - 按 Q 不打了
- ### 游戏ing
  - 长按 Z 蓄力
    - 松开后会根据蓄力点释放常形力 *（就是发射子弹* 
  - 长按 X 为悬浮态 *（就是快移动*
  - 按 C 释放形分 *（也就是 Bomb*
  - 在对话中按 Z 下一则对话
    - 也可以按 X 跳过
  - 按 Esc 休息一下
- ### 休息ing
  - 按 Esc 休息完了
  - 不想玩就按 Q 吧 *（按完就返回主界面了*
- ### 存记录
  - 按 Esc 不存
  - 按 Enter 存 *（存在用户目录的“保存的游戏”文件夹里*
  - 可以打些字 *（最多 8 个字符*

## 说一下规则吧  
- ### K.璃
  - 形点
    - 白色为蓄力点
      - 会根据是否蓄力而释放常形力 *（就是 biu*
    - 蓝色为形力点
      - 加形力 *（就是火力*
    - 绿色为形闪点
      - 加形闪次数 *（闪避！*
  - “矩澜雨” *（Bomb*
    - 每释放一次会消耗 12 点形力
    - 释放后会有 3 秒无敌时间
  - 蓄力
    - 会根据蓄力点来连续释放常形力
    - 最多可以蓄 6 个点
  - 连击 *（捡*
    - 形力点和形闪点才能加连击
    - 拾到任何形点倒计时会重置为 2 秒
    - 倒计时结束会额外加分
- ### 分数
  - 子弹每击中目标 + 64
  - 连击倒计时结束 + 2 ^ 连击（连击 > 0
  - 结算（基础分 + (面关结束分 if 子关 == 6 else 0)
    - 基础
      - 得点结算：得点 * 512
      - 无闪结算：连续无闪过关数 * 4096
      - 连击结算：跟连击倒计时结束加的分一样
    - 面关结束
      - 面数结算：面数 * 16384
      - 形力结算：形力 / 32 * 8192
- ### 弹幕
  - 碰到白色弹幕不会触发形闪
  - 击落砖块生成弹幕概率
    - 第一面：0.17 + 0.03
    - 第二面：0.17 + 0.05
    - 第三面：0.17 + 0.08
- ### 砖块
  - 白色砖块会有“惊喜”哦
