## 按键说明书  
- ### 主界面
  - 按 Z 开始嗨皮
  - 按 C 查看日志 *（没有日志的话就当木鱼吧*
  - 按 Q 不打了
- ### 游戏ing
  - 按 ←→ 左右移动
  - 按 Z 手动攻击
  - 按 X 切换形态 *（特殊状态*
  - 按 Space 释放形分 *（Bomb*
  - 在对话中按 Z 下一则对话
    - 也可以按 X 跳过
  - 按 Esc 休息一下
- ### 休息ing
  - 按 Esc 休息完了
  - 不想玩就按 Del 吧 *（按完就返回主界面了*
- ### 存日志
  - 按 Esc 不存
  - 按 Enter 存 *（存在用户目录的“保存的游戏”文件夹里*
  - 可以打名称上去 *（最多 8 个字符*
- ### 看日志
  - 按 Esc 合上
  - 按 Del 扔掉
  - 翻页则按 ←→

## 说一下规则吧  
- ### K.璃
  - 形点
    - 白色为蓄力点
      - 加蓄力
      - 最多能蓄 6 个点 *（事实上其它点也能加蓄力点*
    - 蓝色为形力点
      - 加形力 *（火力*
      - 最多能蓄 32 个点
    - 绿色为形闪点
      - 加形闪 *（残机*
      - 不会限制点数
  - 形分
    - 每释放一次会消耗 12 点形力
    - 释放后会有 3 秒无敌时间
  - 连击 *（其实是捡形点*
    - 形力点和形闪点才能加连击
    - 拾到任何形点倒计时会重置为 2 秒
    - 倒计时结束会额外加分
  - 形态
    - 正常形态为正常速度 *（废话*
    - 特殊形态会移动的比较快 *（键需要长按哦*
  - 手动攻击 *（键需要配合长按和松开哦*
    - 会根据蓄力点释放常形力 *（发射子弹*
- ### 分数 *（不觉得 2 的乘方数很完美吗*
  - 子弹每击中目标 + 64
  - 连击倒计时结束或子关结束 + 2 ^ 连击 *（连击 > 0*
  - 结算 *（基础分 + (结束分 if 子关 == 6 else 0)*
    - 基础
      - 得点结算：得点 * 512
      - 无闪结算：连续无闪过关数 * 4096
    - 结束
      - 面数结算：面数 * 16384
      - 形力结算：形力 / 32 * 8192
- ### 砖块
  - 击落砖块会
    - 有概率生成弹幕
    - 可能掉落形点 *（每关掉落的形点数是固定的*
  - 白色砖块会有“惊喜”哦
- ### 弹幕
  - 碰到白色弹幕不会触发形闪
  - 击落砖块生成弹幕概率为
    - 0.17 + *（斐波那契数*
      - 第一面：0.03
      - 第二面：0.05
      - 第三面：0.08
