世界观：
	这是个以形状为主的“桃花源”
	它叫抚形地
	从基本到复杂为点*、线*、三角形、四边形和圆
	故此人类主要分为点线人和形人

	地方：
		稳楼：
			一个城镇，盛产角菜的地方
			在这里时不时会看到三角形人
			锐山是这里的最高峰
			想要爬这座山就必须经过三角广场
			（听说这座山的山顶有一栋建筑

		圆湾：
			一个港湾，比较繁华的地方
			海岸线有圆形的轮廓
			有传言说这里曾经是生灵涂炭的地方
			后来有个大陨石砸向此地后没多久就开始生长植物，气候也变得宜人
			这圆形轮廓的海岸线就是证据
			（虽然目前没有证据证实此传言，但说起来好像也没毛病。。。

		众山丘陵：
			就在锐山的背后
			从锐山山顶上看的话就是一群山
			据说每一座山都有一位山主
			但没有听说过有人去过这地方
			所以这是瞎编的（

		远边平原：
			这里就是抚形地北边的边缘了
			这里都是遍地的金黄
			没有人踏足于此地
			没有人知道这里发生过什么
			也没有人知道这地方之外的世界

		云果岛：
			也是抚形地的边缘
			离圆湾很远
			远到看不见它
			跟远边平原不同的是这里有人来到过这
			听他们说这里长着一棵果树

			从这里看四周就是一望无际的大海

	SHA元素：
		这是抚形特有的元素
		由抚形人生成的元素
		本身是不可持久存在的
		但它可以人为通过分子重新组合
		形成各种元素周期表中的元素

	种族：
		点线人：
			是这个世界的普通人类
			但对于我们来说他们就是体育生（
			他们的能力比形人低很多
			想要类似形人的能力要么向他们学习，要么用辅形器
			大多数都选择了后者，因为他们纯靠学习出来的能力很难使出来

		形人：
			有特殊能力的人
			每个形人都有属于自己的独特能力
			可以学习能力，但只能学习自己形种类的
			与点线人相处的非常好

		双人：
			一种特殊的形人
			一般是由两种形人生下来的（其中一方为点、线的除外）
			他们能同时驾驭两种能力且不依赖辅形器
			甚至能比辅形器还要强大
			但随时要做好面向死亡的准备
			因为同时长期具有两种能力
			随时会因此导致机能冲突而毙命
			能活多一天貌似是上天对他们的恩赐
